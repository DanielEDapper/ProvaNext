# WEG Academy | Versão Tailwind minimalista

Esta versão usa Tailwind CSS via CDN e mantém apenas as seções simplificadas dos HTMLs atuais.

## Arquivos

- `index.html`
- `curso.html`
- `sobre.html`
- `assets/img/logo-weg.png`
- `assets/img/placeholder-curso.jpg`
- `assets/js/app.js`

## Observação

Na conversão para Next.js, o aluno deve configurar Tailwind CSS no projeto e não depender do CDN.
